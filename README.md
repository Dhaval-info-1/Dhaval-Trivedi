# Dhaval Trivedi Portfolio & Blog 🚀

Welcome to the repository for Dhaval Trivedi's personal portfolio and developer blog website! This project showcases a premium web interface hosting detailed information about Dhaval's background, open-source work, contact links, and interactive articles.

## 📁 Key Files & Structure

- `index.html`: The main, beautifully styled portfolio lander.
- `blog.html`: A multi-column, elegant blog engine showing publications and developer resources.
- `web.html`: Portfolio project showcase pages.
- `server.py`: A lightweight Python backend serving clean SEO pages and blog server endpoints.
- `manifest.json`: Web app manifest support.

## 🛠️ Local Development

1. **Python Server Setup**:
   To run the local static server with Python, install requirements:
   ```bash
   pip install -r requirements.txt
   ```
2. **Start Server**:
   ```bash
   python server.py
   ```
3. Open `http://localhost:8000` in your web browser.
